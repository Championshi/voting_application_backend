Routers:- 

user Aunthentication
/Signup: POST - create a new account
/login: POST -  log in  to  an existing account . [aadhar card number + password]

Voting:
/candidates: GET - get the list of candidates
/vote/:candidates: POST - vote for specific candidates.

vote Counts:
/vote/counts: GET - get the list of candidates sorted by their vote counts.

User profile:
/profile: GET - Get the user profile information
/profile/password: PUT - change the user's password.

Admin candidate management:
/candidates: POST - create a new candidates
/candidates/:candidateId: PUT - Update an existing candidates.
/candidates/:candidateId: DELET - delete a candidates from the list
